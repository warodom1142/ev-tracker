# ⚡ EV Tracker

เว็บแอปบันทึกการใช้รถไฟฟ้า คำนวณอัตราการใช้ไฟ ระยะทาง และค่าใช้จ่ายจาก
เลขไมล์ แบต% และโหมดขับ ทั้งตั้งแต่เริ่มต้นและทุกครั้งที่จอดชาร์จ

## เริ่มใช้งาน

ไม่ต้องติดตั้งอะไร เปิด `index.html` ในเบราว์เซอร์ได้เลย
(หรือรันเซิร์ฟเวอร์ง่ายๆ เช่น `python3 -m http.server` แล้วเปิด http://localhost:8000)

1. ตั้งค่ารถ: **ความจุแบต (kWh)** จำเป็นต่อการคำนวณ kWh และอัตราการใช้ไฟ
   ใส่ราคาไฟบ้านและราคาชาร์จสาธารณะไว้ด้วย ถ้าอยากให้คำนวณค่าใช้จ่ายอัตโนมัติ
2. บันทึก "จุดเริ่มต้น" ด้วยเลขไมล์ แบต% (และโหมดขับ)
3. ระหว่างทาง กรอก "ระหว่างทาง" ทุกครั้งที่ต้องการจุดเช็ก (เช่น ก่อนขึ้นทางด่วน, ตอนจอดพัก)
4. ถึงจุดชาร์จ กรอก "ชาร์จ" โดยใส่แบต% ก่อนชาร์จและหลังชาร์จ
   และถ้ารู้ให้ใส่ kWh ที่ตู้แจ้งและค่าใช้จ่ายจริงด้วย
   ถ้าไม่ใส่ แอปจะคำนวณ kWh จากการเปลี่ยนของแบต% และค่าไฟจากราคาที่ตั้งไว้

### โหมดขับ
โหมดที่กรอกใน entry จะนับกับระยะทาง**ตั้งแต่บันทึกก่อนหน้า**จนถึงบันทึกนี้

### ระยะที่โชว์บนจอ / Trip meter
เป็นข้อมูลอ้างอิงเฉยๆ ไม่ได้ใช้คำนวณ เพื่อให้เทียบกับค่าที่แอปคำนวณเองได้

## สูตรที่ใช้

| ค่า | สูตร |
|---|---|
| ระยะช่วงนี้ | ไมล์ปัจจุบัน − ไมล์บันทึกก่อนหน้า |
| kWh ที่ใช้ | (แบต% ก่อน − แบต% ปัจจุบัน) ÷ 100 × ความจุแบต |
| kWh/100 km | kWh ที่ใช้ ÷ ระยะ × 100 |
| kWh ที่ชาร์จ | ค่าที่กรอก หรือ (แบต% หลัง − ก่อน) ÷ 100 × ความจุ |
| ค่าชาร์จ | ค่าที่กรอก หรือ kWh × ราคาตามประเภทการชาร์จ |
| ค่าใช้จ่ายจริง/กม. | ค่าชาร์จรวม ÷ ระยะรวม |
| ค่าไฟโดยประมาณ/กม. | (kWh/100 km ÷ 100) × ราคาเฉลี่ยต่อ kWh |
| ประสิทธิภาพการชาร์จ | พลังงานที่แบตได้รับ ÷ kWh ที่ตู้แจ้ง (เฉพาะที่กรอกเอง) |

> ข้อจำกัด: อัตราการใช้ไฟคิดจาก **แบต%** ซึ่งเป็นค่าที่จอแสดงผล ค่าความละเอียด 1% ทำให้
> ระยะสั้นๆ มีค่าคลาดเคลื่อนได้ ควรบันทึกเป็นช่วงที่ยาวพอ (หลาย km ขึ้นไป)

## ข้อมูล

- เก็บใน **localStorage ของเบราว์เซอร์** (ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล)
- ใช้ **Backup JSON** เป็นระยะ และ **Import JSON** เพื่อย้ายไปเครื่องอื่น
- **Export CSV** เปิดใน Excel/Google Sheets ได้ (มี BOM รองรับภาษาไทย)

## ทดสอบ

```bash
npm test
```

ทดสอบเฉพาะตรรกะคำนวณใน `calc.js` (ต้องใช้ Node 18+)

## โครงสร้างไฟล์

```
index.html     หน้าเว็บ
style.css      สไตล์ (รองรับ dark mode)
app.js         UI, การบันทึก, export/import
calc.js        ตรรกะคำนวณ (แยกจาก DOM ทดสอบได้)
tests/         unit test
```

## ต่อยอดได้ในอนาคต
- แก้ไข entry ที่บันทึกแล้ว (ตอนนี้ทำได้แค่ลบแล้วกรอกใหม่)
- กราฟ kWh/100 km ตามเวลาและตามอุณหภูมิ
- ซิงก์หลายอุปกรณ์ → จะต้องมี backend/ฐานข้อมูล (เช่น Supabase/Firebase) ซึ่งยังไม่จำเป็นถ้าใช้คนเดียวบนเครื่องเดียว
